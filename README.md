# پخش‌یار — شروع پروژه

این مخزن شامل نسخه شروع وب/PWA برای مدیریت کالا، موجودی و ثبت سفارش است.

## اجرای آزمایشی
فایل‌ها را روی GitHub قرار دهید و از Settings → Pages، شاخه `main` و پوشه `/ (root)` را برای انتشار انتخاب کنید.

## وضعیت امکانات
- رابط فارسی و راست‌چین
- ثبت کالا با تعداد کارتن و تعداد در هر کارتن
- ثبت سفارش و کسر موجودی
- گزارش جمع خرید موجودی، فروش سفارش‌ها و سود ناخالص سفارش‌ها
- ذخیره محلی روی همان مرورگر و پوسته PWA آفلاین

## مواردی که هنوز پیاده‌سازی نشده‌اند
- ورود امن مدیر، ویزیتور و راننده و الزام عکس پروفایل
- پایگاه داده آنلاین و همگام‌سازی چندکاربره
- صف تغییرات آفلاین و حل تعارض همگام‌سازی
- تاریخچه کامل تغییرات سفارش
- چاپ مستقیم از طریق نقطه اتصال/وای‌فای
- بسته‌بندی APK و امضای نسخه انتشار

این موارد برای نسخه نهایی باید جداگانه پیاده‌سازی و آزمایش شوند. اطلاعات این نسخه آزمایشی فقط در مرورگر همان دستگاه ذخیره می‌شود و برای اطلاعات واقعی کسب‌وکار استفاده نشود.
